Bitdeer AI Starter Pack for Cal Hack Welcome to Cal Hack! Power your hackathon project with Bitdeer AI's Model Studio. We are providing API credits for all participants to build cutting-edge applications using top-tier AI models. What We Provide Bitdeer AI gives you access to the models you need for an AI hackathon project. Your API credits apply across the following: ● Chat Models: Generate and process conversational text. We offer both text-only and multimodal (text + image) models. ● Embeddings (BAAI/bge-m3): Convert text into numerical vectors for semantic search, RAG (Retrieval-Augmented Generation), and clustering. ● Reranker (BAAI/bge-reranker-v2-m3): Reorder search results by relevance to improve your retrieval pipelines. ● Image Generation (byteplus/Seedream-5.0-Lite): Create visual assets from text prompts. How to Get Started 1. Create an account at [bitdeer.ai](http://bitdeer.ai). 2. Submit the credit request form to receive your assigned Model Studio credits. 3. Access Model Studio (located in the left sidebar after signing in at [bitdeer.ai](http://bitdeer.ai)) to: ○ Create a new API key for authenticating request calls. ○ Explore and test available model offerings. ○ Monitor your API credit usage across the event.
